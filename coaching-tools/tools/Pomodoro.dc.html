Pomodoro planner

Attention is a muscle: it works in sets. Twenty-five minutes on one task, five off, four times, then a proper break. This sheet plans a two-hour block and catches the distractions.

Why this may help

Short focus periods can make a task easier to start and help you notice distractions without demanding hours of concentration.

1

Choose one task per pomodoro and write it down. If it is bigger than 25 minutes, split it; if smaller, batch it.

2

Set a timer and work only on that. Anything else that comes to mind goes in the parking lot, not in your head.

3

Break properly. Stand up, move, no screens. Tick the pomodoro and start the next.
