# Coaching toolbox privacy

Each worksheet saves answers to local browser storage only. Answers are not submitted to ACSIS, GitHub, Wix or another coach. The coach or client can choose to download a PDF and share that file themselves.

The worksheets use locally hosted fonts, images, styles and runtime files. A restrictive browser policy blocks form submissions and connections to other websites. Ordinary reference links open only when a user chooses them.

The toolbox and handbook use the same worksheet files, but their saved answers remain separate. Clearing a worksheet removes its saved answers from that browser.
